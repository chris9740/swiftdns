# Swiftdns Documentation

Swiftdns is a privacy-focused DNS-over-HTTPS proxy designed for power users.

## Key Features

-   **Privacy First**: All DNS queries encrypted via HTTPS
-   **Domain Filtering**: Block ads, trackers, malware with custom rules
-   **Tor Support**: Route queries through Tor for anonymity
-   **Hot Reload**: Filter changes apply instantly
